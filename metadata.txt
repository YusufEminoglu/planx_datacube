about=PlanX DataCube Lab brings a complete space-time pipeline to QGIS: aggregate events into a fishnet panel, build (X×Y×T×V) cubes from vector or raster time series, inspect them in an integrated heatmap / 3D voxel / per-cell series Workbench, run Emerging Hot Spot Analysis (EHSA) with 17 pattern classes, test local outliers and trends, and forecast future values with ARIMA, Random Forest or exponential smoothing. CF-style netCDF export records real time coordinates, cell bounds and CRS metadata so the cube is ready for downstream science. Online User Manual & Documentation: https://geophilo.com/planx_datacube/ | If you find this plugin helpful, please consider starring the repository on GitLab (https://gitlab.com/geophilo1/planx_datacube)!
